# Metaphor High Pitch Fix
> Audio Mod that replaces certain audio cues with silence

Unfortunately, it is not just one audio file that has the high pitched background noise.
I will be adding more updates to this mod, fixing more sounds, as I play through the game.

## Installation
1. Install Reloaded 2: https://reloaded-project.github.io/Reloaded-II/QuickStart/
1. Install Ryo
    1. Download the latest `Ryo.Reloaded<version>` zip/7z file from: https://github.com/RyoTune/Ryo/releases
    1. Follow this guide to install: https://reloaded-project.github.io/Reloaded-II/QuickStart/#install-a-mod
1. Install this mod
    1. Download the latest release from: https://github.com/StrongJoshua/metaphor-high-pitch-fix/releases
        1. Follow the same guide as for Ryo to install
    1. Alternatively, install from [GameBanana](https://gamebanana.com/sounds/92358)
        1. This version may be out of date, but Reloaded should prompt you to update automatically next time you launch Reloaded
1. Make sure both mods are enabled (have a `+` icon next to their names in Reloaded's tab for Metaphor)
1. Make sure Ryo is loaded first (above this mod in the list)
1. Launch the game using Reloaded

## How to Contribute
1. Follow this guide: https://ryotune.github.io/guides/audio/audio-replacement-ryo/#replacing-audio
  1. This will show you the format of audio files in the mod and how to get the name of the one you want to replace
1. Copy one of the existing audio replacement files
1. Paste the copy into the correct cue category directory
1. Rename it to your cue's NAME (not ID, this is just easier for tracking)
1. Launch the game and verify the audio is fixed
1. Submit a pull request
